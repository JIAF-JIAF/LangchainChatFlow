# 智能客服 Agent - 项目总结

## 已完成功能

### 1. 核心架构
- Flask Web 服务框架
- AI 服务 API 集成（兼容 OpenAI SDK）
- 模块化设计，易于扩展
- 统一 AI 客户端管理 (AIClient)

### 2. 知识库系统
- 文本向量化存储模块 (vector_stores/)
- 自动检测知识库是否存在，向量为空时自动重新向量化
- 首次运行自动向量化原始文本（支持 .txt、.pdf、.docx）
- 基于余弦相似度的内容检索
- Chroma 向量数据库支持（兼容 langchain-chroma）
- DashScope Embeddings 支持（阿里云百炼向量化）
- 向量化失败安全处理

### 3. AI 助手模块
- AI 助手初始化和管理 (assistant.py)
- 自动创建/加载助手
- 会话线程管理
- 对话上下文维护
- 工具调用支持

### 4. 工具系统
- 工具定义和执行框架 (tools/)
- 天气查询工具
- 天气推荐工具（支持链式调用）
- 表单提交工具
- 可扩展的工具接口
- 基于 StructuredTool 的统一工具调用

### 5. FewShot 学习系统
- LengthBasedExampleSelector 动态示例选择
- 基于输入长度自动裁剪示例
- 默认示例对话库 (DEFAULT_FEW_SHOT_EXAMPLES)
- 可自定义的 FewShot 示例配置

### 6. Web API
- GET /start - 服务状态检查
- POST /chat - 对话接口
- 会话管理(session_id)
- 错误处理和状态码

### 7. 配置管理
- config.json - 系统配置
- 模块化配置读取
- 示例知识库数据

### 8. 文档
- 使用说明.md - 详细文档
- 启动指南.md - 快速入门
- 项目总结.md - 本文件

## 核心功能说明

### 工作流程

1. **启动阶段**
   - 加载配置文件
   - 初始化 AI 客户端 (AIClient)
   - 初始化知识库（向量化文本）
   - 创建/加载 AI 助手
   - 启动 Flask 服务

2. **对话阶段**
   - 接收用户消息
   - 创建/获取会话线程
   - 调用 AI 助手处理
   - 检测工具调用需求
   - 执行工具（如天气查询、表单提交）
   - 返回 AI 回复

3. **工具调用**
   - AI 判断是否需要调用工具
   - 解析工具参数
   - 执行对应功能
   - 将结果返回 AI
   - 生成最终回复

### FewShot 学习流程

1. **初始化阶段**
   - 加载 DEFAULT_FEW_SHOT_EXAMPLES 示例列表
   - 创建 LengthBasedExampleSelector 实例
   - 将示例注入到系统提示模板

2. **对话阶段**
   - 根据输入长度选择合适的示例
   - 将示例拼接到系统提示中
   - 发送给 AI 模型处理

## API 接口

#### GET /start
检查服务状态

**请求:**
```
GET http://localhost:5000/start
```

**响应:**
```json
{
  "status": "ready",
  "message": "客服系统已就绪 (LangChain)",
  "model": "qwen-plus",
  "knowledge_base": true
}
```

#### POST /chat
处理对话请求

**请求:**
```json
{
  "message": "用户输入",
  "session_id": "可选会话ID"
}
```

**响应:**
```json
{
  "reply": "AI回复内容",
  "tool_calls": [],
  "session_id": "会话ID",
  "finished": false
}
```

## 技术栈

- **后端框架**: Flask 3.0.0
- **AI SDK**: OpenAI 1.12.0（兼容阿里云百炼）
- **向量化**: text-embedding-v3
- **AI 模型**: qwen-plus
- **向量数据库**: Chroma
- **HTTP 客户端**: requests 2.31.0
- **数值计算**: numpy 2.4.4
- **LangChain**: >= 0.3.0 (Agent、工具框架、ExampleSelector)

## 使用方法

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置 API Key
编辑 `config.json` 文件，填入 API Key

### 3. 准备知识库
编辑 `knowledge_base/raw_knowledge.txt`，添加业务知识

### 4. 启动服务
```bash
python app.py
```

### 5. 测试
```bash
# 另一终端运行
python test.py
```

## 自定义扩展

### 修改系统提示词

编辑 `modules/prompt/__init__.py` 中的 `CUSTOMER_SERVICE_PROMPT_TEMPLATE` 变量

### 自定义 FewShot 示例

编辑 `modules/prompt/__init__.py` 中的 `DEFAULT_FEW_SHOT_EXAMPLES` 列表

### 添加工具

在 `modules/tools/` 目录创建新工具文件，定义工具逻辑后注册到工具列表

### 更新知识库

1. 在 `knowledge_base/` 修改文档
2. 重启服务自动重新向量化
